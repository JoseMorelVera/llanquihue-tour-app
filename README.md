📘 Descripción general del sistema: Este proyecto es para la evaluacion formativa de la semana 7 del curso desarrollo aplicado a objetos, se basa en la continuacion del proyecto LlanquihueTourApp, esta vez modificando las clases de Servicio turistico como clase padre y las calses Ruta gastronominca, Paseo lacustre y Excursion cultural como clases hijas, agregandoles la funcion de mostrarInformacion, creando herencia con sus clases hijas y @Override para modificar esta informacion dependiendo de que tipo se seleccione, además creando una lista en un ArrayList para poder guardar estos obejetos y poder verlos por consola. 

🧱 Estructura general del proyecto 📁 src/ ├── UI/ # Clase principal con el método main ├── model/ # Clases de dominio (Cliente, Direccion, Empleado, Guia, Persona, Planes, ServicioTuristico, RutaGastronomica, PaseoLacustre y ExcursionCultural) ├── data/ # Clases para crear el ArrayList y creacion de objetos (GestorServicioTuristico)
