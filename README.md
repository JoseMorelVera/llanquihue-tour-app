📘 Descripción general del sistema: Este proyecto es para la evaluacion sumativa de la semana 8 del curso desarrollo aplicado a objetos, se basa en la continuacion del proyecto LlanquihueTourApp, esta vez creando una ArrayList para la contencion de obejtos, teniendo en cuanta que dentro de ella se realiza una instanceof, ya que la lista de esta semana tendra 3 tipos de datos distintos, además implementando el metodo mostrarResumen en la clase Registrable que se implementara dento de la clase Recurso agencia, que sera la clase padre y en las clases hijas que son guia turistico, vehiculo y colaborador externo, permitiendonos modificar los datos mostrados por pantalla dependiendo el objeto que se tome de la lista mencionada.

🧱 Estructura general del proyecto 📁 src/ ├── IU/ # Clase principal con el método main ├── model/ # Clases de dominio (Cliente, Direccion, Empleado, Guia, Persona, Planes, ServicioTuristico, RutaGastronomica, PaseoLacustre, ExcursionCultural, Registrable, RecursoAgencia, GuiaTuristico, Vehiculo, ColaboradorExterno) ├── data/ # Clases para crear el ArrayList y creacion de objetos (GestorEntidades)
